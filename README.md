## 사진 자료

교과서 사진은 저작권 때문에 공개 웹사이트에 올릴 수 없어서, 같은 장면의 위키미디어 공용 사진(퍼블릭 도메인 또는 CC BY-SA)을 썼습니다. 출처와 라이선스는 페이지 맨 아래에 적어 두었으니 지우지 마세요.

- 교과서와 같은 사진·장면: 런던 밸럼 버스(1940), 쾰른(1945), 도쿄일일신문 기사(1937), 아우슈비츠 정문, 희생자들의 신발
- 새로 추가한 사진: 안네 프랑크(1942), 히로시마 버섯구름(1945), 난징 대학살 기념관 조각, 평화의 소녀상(호주 시드니)
- 넣지 못한 교과서 자료: 작센하우젠 생체 실험실 사진, 김순덕 할머니의 그림 「끌려감」, 위안소 분포도 → 수업 때 교과서로 보여 주기
